# Fallbacks as a person's standing setting (L-142)

*open · 37.2*

## Later
Zach, 21 Nov: everyone seems always to fall back to firewood, which should not be the case; revisit; maybe a setting that optionally stays unset at the start and that they can set or adjust whenever they want; to be discussed and built with the standing rules for how a household's food is shared each night ([[W-37 Standing rules|W-37]]).
