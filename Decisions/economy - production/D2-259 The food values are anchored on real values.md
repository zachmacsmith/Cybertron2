# The food values are anchored on real values (D2-259)

*live · 20 Nov · spec: [[economy - production|economy/production]]*

## The rule
**The food values are anchored on real values ([[D2-258 The food values are put on one physical basis|D2-258]]): a value within about 20% of its FoodData Central figure is kept as it is; balance is made through named levers (food per unit of work, run and stock sizes, gear holds, spoilage, the compressed year), each departure from the real value written beside the data with its factor and reason**
