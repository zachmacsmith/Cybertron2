# Some signs carry between nodes (D2-74)

*live · 23 Oct · spec: [[environment - scheduler|environment/scheduler]], [[environment - visibility|environment/visibility]]*

## The rule
**Some signs carry between nodes:** a sign's kind says whether and how far it carries, and the edge's terrain decides what is experienced at the far end (open plains carry sight far, a mountain ridge blocks it, a forest path hides it), worked out by the engine from edge and node data
