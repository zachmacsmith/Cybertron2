# Live run 1 is a set of small runs, not one big run (D2-335)

*live · 23 Nov*

## The rule
**Live run 1 is a set of small runs, not one big run: each run either longer with fewer people or, if larger, shorter; each set compared with null runs, including how things were before the rebuild; read for a qualitative, holistic sense of whether the new systems changed things, how, and whether for the better, not for statistical significance. Replaces [[D2-331 Live run 1 has a comparison arm|D2-331]]'s single long main arm.**

## Where it came from
conversation (23 Nov: "For the live run, I want you to not just do one big run (eg the previous calibration runs used too much usage) have some that are either longer and smaller or if at all larger then shorter. Design sets of smaller runs with null runs comparing to how things were before the rebuild. We don't need any findings with statistical significance but aiming for qualitative holistic sense of if the new things have changed things if so how and if it is for the better")
