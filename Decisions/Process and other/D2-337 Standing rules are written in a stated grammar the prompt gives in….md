# Standing rules are written in a stated grammar the prompt gives in… (D2-337)

*live · 23 Nov*

## The rule
**Standing rules are written in a stated grammar the prompt gives in full (each kind and its fields: rule, goods, to / from / in, qty, by, when, unless, words); the engine reads the fields, not the words; 'words' is the person's own sentence, kept and shown beside the engine's reading; a rule missing a field is refused saying exactly which field and its form. This replaces [[D2-274 One book of standing rules per household and per person covers both…|D2-274]]'s rule set 'in the agent's own sentence' and the word-reading added in [[W-102 Fix the act shapes' interface faults found in live run 1's rebuilt arm|W-102]].**
