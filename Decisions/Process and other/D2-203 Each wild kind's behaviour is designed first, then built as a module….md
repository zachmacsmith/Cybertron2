# Each wild kind's behaviour is designed first, then built as a module… (D2-203)

*live · 9 Nov*

## The rule
(proposals/wild_behaviour.md): a kind, or a pattern several kinds share, may have its own code, which perceives only through the animal interface and acts only through the engine's primitives, as agents act through verbs; the food web stays the population base

## Where it came from
conversation ("Animals can add specific mechanisms / code but it should just be cleanly modular ... only through the normal ways of acting with the world through the engine"; "Yes, I do want the design per wildlife and then each has modules")

## What it replaced
"no kind has code of its own" (wildlife.md §12, wild_systems.md §10)
