# D2-242 · Subsistence test worlds

*live · 20 Nov*

## The rule
**Subsistence test worlds: a village must be able to live off the runs alone, and off hunting alone; at medium skill and capital it survives, and with more skill or capital it makes a surplus up to some bound, since a surplus in isolation is what makes specialisation and trade possible; built as a set of calibration worlds, beside the calibration suite ([[D2-228 Calibrate across a distribution of worlds|D2-228]]) [no spec]**

## Where it came from
conversation (20 Nov: "can a village survive off just runs (should be possible?) can a village survive off just hunting (should be possible). Each of these should be possible for relatively skilled / medium skill / capital and able to produce surplus up to some amount if there is greater capital / skill ... which is necessary in isolation for specialisation and trade to be possible")
