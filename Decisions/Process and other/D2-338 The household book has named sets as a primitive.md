# The household book has named sets as a primitive (D2-338)

*live · 23 Nov*

## The rule
**The household book has named sets as a primitive: a household (or a person) names a set of people (from its members, or built-in sets such as children, elders, workers, everyone) or a set of goods (items or kinds), and every rule may name a set wherever it names a person or a good; a set's members are treated alike, and an ordered list of sets gives an order (eat everything in set A first, then B).**
