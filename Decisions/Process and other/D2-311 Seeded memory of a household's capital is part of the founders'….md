# Seeded memory of a household's capital is part of the founders'… (D2-311)

*live · 23 Nov*

## The rule
**Seeded memory of a household's capital is part of the founders' 20-line budget, not added on top, and is written together with the livelihood it belongs to (a mill household's milling lines carry the mill): capital, livelihood, acts and memory are one set.**
