# No worked example of a conditional rule is added to the rules block (D2-344)

*live · 23 Nov*

## The rule
**No worked example of a conditional rule is added to the rules block (agents anchor on examples); whether an example changes how they write rules is tested instead by a targeted A/B prompt replay, with and without it.**

## Where it came from
conversation (23 Nov: "Do everything else but not this one don't add the example they can figure it out. Or maybe just test in targeted a b prompt tests if they treat things different with the example. I've found they tend to anchor too much on examples often")
