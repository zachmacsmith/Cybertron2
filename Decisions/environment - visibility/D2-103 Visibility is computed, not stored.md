# D2-103 · Visibility is computed, not stored

*live · 23 Oct · spec: [[environment - visibility|environment/visibility]]*

## The rule
**Visibility is computed, not stored:** a value that emerges each day from the environment (cover and vegetation, a standing crop, snow, smoke as a short-lived state near fires, ambient loudness, the weather)

## Where it came from
visibility.md §7

## What it replaced
visibility as a stored variable
