# A field carries one crop for each holding on it:

- **state**: live
- **source**: conversation ("option C for crops, go ahead with plot shares")
- **replaces_text**: one crop record and one sower a field

## Text
**A field carries one crop for each holding on it:** with plot shares ([[D2-163 Land is held in plot shares within a parcel|D2-163]]), each holder's plots in a field carry their own crop (kind, seed, broken share, weeding, fertility), so one field can hold barley on the Reeds' plots and beans on the Coles'; the field stays one place and one line; a herd on the field tramples or grazes whatever stands there, so a common rotation comes from custom or agreement, never a rule
