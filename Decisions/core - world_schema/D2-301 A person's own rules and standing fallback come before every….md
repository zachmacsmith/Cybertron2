# A person's own rules and standing fallback come before every… (D2-301)

*live · 22 Nov · spec: [[core - world_schema|core/world_schema]]*

## The rule
**A person's own rules and standing fallback come before every household chore, keeping chores included ([[D2-274 One book of standing rules per household and per person covers both…|D2-274]]'s precedence everywhere); people start with no personal fallback and the defaults do not push them to set one; units left unused are rest, and a person may set units to rest on purpose (rest has no effect until fatigue is built).**

## Where it came from
conversation (22 Nov: "Your own rule should overrun chores. They just by default don't start with personal fallbacks and that's their fault. Only if they set personal fallbacks. I choose (b). The defaults just shouldn't push too much for them to set fallbacks. Unused units should mean they just rest and they can also set units purposefully to rest. Right now this won't do anything but later it will when we add fatigue")
