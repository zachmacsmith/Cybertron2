# An agent rewrites its one memory each stretch, within a length that… (D4-61)

*live · 24 Oct · spec: [[information - memory|information/memory]]*

## The rule
**An agent rewrites its one memory each stretch, within a length that grows with its age:** keep what still matters, add from these days only what it will want later, leave the rest; the length rises fastest when young and levels off (ceiling about 600 words); the engine keeps no list of events on its behalf; weak models (Haiku) keep [[D4-28 Agents write their own memory at set times|D4-28]]'s queue

## Where it came from
conversation ("rather than forming a new memory every 3 days, they rewrite their memory section ... a scheduler that decides how the token length ... changes over time ... up to them rather than forced by the engine"; then "you can implement your recommended memory changes"); proposals/memory_rewrite.md; review 38.36 (live tests of seven instructions on two models)

## What it replaced
[[D4-28 Agents write their own memory at set times|D4-28]]'s queue of stretch memories (the last six) and the engine's list of marked events, for all but weak models
