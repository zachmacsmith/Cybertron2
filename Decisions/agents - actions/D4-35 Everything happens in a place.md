# Everything happens in a place

- **state**: live
- **source**: conversation ("Things happening in other nodes shouldn't even be able to accidentally see them. Every single event should occur in a place."); proposals/place.md
- **replaces_text**: M1's per-feature node filters

## Text
**Everything happens in a place**: every entity and every event is at a node or on a road; nothing that happens at one node can be seen at another, except as people, messages or goods carry it; the engine is built so that this cannot fail by accident
