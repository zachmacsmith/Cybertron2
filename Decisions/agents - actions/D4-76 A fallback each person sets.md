# A fallback each person sets (D4-76)

*live · 2 Nov · spec: [[agents - actions|agents/actions]]*

## The rule
**A fallback each person sets:** besides the plan, a reply may give `fallback` acts; units left over when the plan is done (an act refused, a field reaped out, a plan too short) go to them, in order and again, until the units are used or none can be done; free acts and travel are not taken as fallback

## Where it came from
conversation ("the fallback option (they should be able to set it themselves)"); proposals/fallback.md (retrospective)

## What it replaced
units left unused when an act was refused
