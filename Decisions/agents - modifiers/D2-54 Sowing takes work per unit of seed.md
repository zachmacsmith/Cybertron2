# Sowing takes work per unit of seed (D2-54)

*live · 23 Oct · spec: [[agents - modifiers|agents/modifiers]], [[economy - production|economy/production]]*

## The rule
**Sowing takes work per unit of seed,** so an agent's day sows only so much; seed can be **broadcast** (fast, wastes seed) or **dibbled** (about three times the work, about 40% less seed for the same harvest)

## Where it came from
farming.md §5

## What it replaced
sowing as a fixed cost per plot
