# Skill by practice on all work (D2-52)

*live · 23 Oct · spec: [[agents - modifiers|agents/modifiers]], [[economy - production|economy/production]]*

## The rule
**Skill by practice on all work,** basic work included: doing a kind of work raises one's skill at it, which raises yield or cuts work; an ordinary adult is about x1.0 at basic work and a master about x1.5; a learned trade runs from about x0.5 (novice) to x2.0 (master); seeded specialists start skilled (curve and rates to calibrate)

## Where it came from
02c §5, 02d; conversation ("is supposed to exist already")
