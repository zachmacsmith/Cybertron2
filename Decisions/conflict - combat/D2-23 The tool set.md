# The tool set (D2-23)

*live · 23 Oct · spec: [[conflict - combat|conflict/combat]], [[economy - goods|economy/goods]], [[economy - livestock|economy/livestock]], [[economy - production|economy/production]], [[economy - transport|economy/transport]]*

## The rule
**The tool set:** hand tools as one good with grades (crude, then metal); the plough (needs an ox); carts; weapons (fighting, and hunting); **traps** (catch game overnight while the trapper is elsewhere); **harness** (an ox pulls) and **saddle** (a horse carries a rider). Armour, nets, boats and the seed drill wait (proposals/economy_later.md)

## Where it came from
02j §3; conversation

## What it replaced
02g's single "tools and blades" good
