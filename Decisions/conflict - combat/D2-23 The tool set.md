**The tool set:** hand tools as one good with grades (crude, then metal); the plough (needs an ox); carts; weapons (fighting, and hunting); **traps** (catch game overnight while the trapper is elsewhere); **harness** (an ox pulls) and **saddle** (a horse carries a rider).
