# Everything new in the engine is built within the agreed architecture… (D2-353)

*live · 24 Nov · spec: [[process - how_we_work|process/how_we_work]]*

## The rule
**Everything new in the engine is built within the agreed architecture without being asked each time: features are data on the core's general mechanisms (feature_packages.md P3), behaviour attaches to declared properties of rows and never to a thing's name, interface and signs are rendered from data, and every registry is checked when it loads. Every brief states it, every review checks it (named branches, hand-written text, word lists, silent skips, maker patches), and a guard test fails on new branches on a named thing.**
