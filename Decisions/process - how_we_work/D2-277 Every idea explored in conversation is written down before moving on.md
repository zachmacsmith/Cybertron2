# Every idea explored in conversation is written down before moving on (D2-277)

*live · 22 Nov · spec: [[process - how_we_work|process/how_we_work]]*

## The rule
**Every idea explored in conversation is written down before moving on: into its thread's proposal, or, if it is not part of it, into its own proposal marked exploration (or speculation), linked to the thread; nothing explored is left only in the conversation**

conversation (22 Nov: "conversation (22 Nov: "Even if not the main proposal they should at least by default getting their own proposals linked to it marked as exploration / speculation so as soon as I move on we know what else was explored")")
