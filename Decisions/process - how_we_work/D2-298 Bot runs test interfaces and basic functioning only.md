# Bot runs test interfaces and basic functioning only (D2-298)

*live · 22 Nov · spec: [[process - how_we_work|process/how_we_work]]*

## The rule
**Bot runs test interfaces and basic functioning only; they make no decisions except those built into them, so they are not read as evidence of behaviour or of whether a world is too rich or too poor. Live runs carry that signal (starving included).**

## Where it came from
conversation (22 Nov: "Stop overcorrecting on bot runs they can test basic interfaces and functioning but ofc they won't actually do things and make decisions unless you build it in yourself. Live runs are the ones where starving is actually signal")
