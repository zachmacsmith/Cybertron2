# D2-32 · The settlement rule

*live · 23 Oct · spec: [[economy - agreements|economy/agreements]], [[world - roads|world/roads]]*

## The rule
**The settlement rule:** an obligation exists anywhere; it is paid automatically only where there is a path (in person at one node, in one ledger, by a carrier); otherwise it accrues as arrears, paid first later
