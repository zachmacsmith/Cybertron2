# D4-85 · A seeded building gets some free floor by default

*live · 2 Nov · spec: [[economy - buildings|economy/buildings]]*

## The rule
**A seeded building gets some free floor by default:** 3 spaces beyond what its fittings and stores take, unless its world file says (`free`), and only while its parcel keeps ground for a small room (6 spaces); Combe's Green widened to size 2 so Hobb House has it

## Where it came from
conversation ("set a default", on OPEN [[Q-24 Built for the building package|Q-24]])

## What it replaced
seeded buildings with no free floor unless the file gave it (02zh §1)
