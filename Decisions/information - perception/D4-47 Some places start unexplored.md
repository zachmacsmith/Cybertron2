# Some places start unexplored (D4-47)

*live · 23 Oct · spec: [[information - perception|information/perception]], [[world - edges|world/edges]], [[world - places|world/places]], [[world - roads|world/roads]]*

## The rule
**Some places start unexplored:** a world can hold nodes nobody knows; from where its road starts, the way is seen only as an unexplored way; whoever follows it learns the place, and others learn it by being told or led there. Camps and portable shelter ([[D2-68 Camps and portable shelter|D2-68]]) are the means of travelling and staying there

## Where it came from
conversation ("can it have a few nodes that start unexplored, like e.g. a quarry?"; "bedrolls, tents, camps ... which can be used for travel to the unexplored lands")
