# Some places start unexplored:

- **state**: live
- **source**: conversation ("can it have a few nodes that start unexplored, like e.g. a quarry?"; "bedrolls, tents, camps ... which can be used for travel to the unexplored lands")

## Text
**Some places start unexplored:** a world can hold nodes nobody knows; from where its road starts, the way is seen only as an unexplored way; whoever follows it learns the place, and others learn it by being told or led there. Camps and portable shelter ([[D2-68 Camps and portable shelter|D2-68]]) are the means of travelling and staying there
