# One's beasts as one last knew of them, kept short (D4-73)

*live · 2 Nov · spec: [[information - perception|information/perception]]*

## The rule
**One's beasts as one last knew of them, kept short:** seeing one's household's beasts, one counts them, so groups that are no more (rejoined, led off, dead) leave one's list; the latest four groups are shown, the rest counted

## Where it came from
conversation ("maybe we should do something so it doesn't get spammed full of herd groups"); proposals/sign_rules.md (retrospective)

## What it replaced
one entry kept for every group ever seen
