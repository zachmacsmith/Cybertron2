# How bare a place is, is a perception like any other (D4-50)

*live · 23 Oct · spec: [[information - noticing|information/noticing]], [[information - perception|information/perception]]*

## The rule
**How bare a place is, is a perception like any other:** its signs are more likely to be noticed the barer it is, so some notice before ever working there and others only when they fail; some notice only when they cannot find food. What one has seen or found shows in one's own description of the place

## Where it came from
conversation ("Sure, they tell them that it is picked bare. Tho this should be a perception like any other, with salience depending on how bare it is, so some people will notice early before even foraging while others don't notice until they fail. There should be some people that only notice when they can't find food")

## What it replaced
the place list always saying what can be done at a place, bare or not
