# The land's base fertility, multiplicative

- **state**: live
- **source**: conversation (37.2's fixed/slow/fast land properties; Zach: "river plains are very fertile but even adding dung can't make desert sand fertile enough"; "yes multiplicative if that makes sense")
- **replaces_text**: new

## Text
**The land's base fertility, multiplicative** (proposals/base_fertility.md, retrospective): a parcel's `land.base_fertility` multiplies every level its soil comes back toward (rest, grazing, dung, a crop's restoring) and a new clearing's start, so dung cannot make poor ground rich; the capacity model follows; default 1.0 (older worlds unchanged); world schema version 4
