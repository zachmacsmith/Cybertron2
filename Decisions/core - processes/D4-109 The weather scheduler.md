# The weather scheduler

- **state**: live
- **source**: conversation ("weather can vary regionally, no?"; "Should we have a simulated evolving climate?"; "I think diseases and ecology should not be in the same system as weather? anyway, can you build out this base weather scheduler?"; "are we able to change the scale of weather changes to quicker if we want as a parameter?")
- **replaces_text**: the drawn spells of [[D2-69 The scheduler's layers|D2-69]] (a run of a type is now a spell); [[D2-76 Eras in four families|D2-76]]'s era families, for weather

## Text
**The weather scheduler** (proposals/weather_scheduler.md, retrospective): a world with a `climate:` block draws its weather from its seed: an era (climate only: disease and ecology are other systems), the year's anomaly, the day's weather type (after Lamb's types), and local fields correlated between near villages and carried from day to day; physical values at each node with the engine's labels derived; the night, crops, woods, decay and signs read their own place's weather; eras hold through a run unless set to move, at a pace a world sets; without the block the hand-written spells stay
