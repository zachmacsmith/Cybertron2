# Carrying capacity is measured, by level, from the engine's own rules (D4-102)

*live · 7 Nov · spec: [[core - processes|core/processes]], [[measurement - capacity|measurement/capacity]]*

## The rule
**Carrying capacity is measured, by level, from the engine's own rules:** cybertron2/capacity reports, for each node and the region, the people the land feeds for good at five levels (bare, as it stands, worked, best, ceiling) as a ratio to the people there; fuel as its own need; stores as a buffer with the days to the first own harvest and the crops the frost takes first; a run's horizon; each level's work and capital (a production graph of every technique); space (reach, expansion outward). The night's rules become pure engine functions both call (regrow, spoil_rate, crop_base, frost_kills and others), with agreement and guard tests (spec/measurement/capacity.md)

## Where it came from
conversation ("Is there already a built in engine module that analyses the lands carrying capacity etc.? If not, build this (as an abstracted, well modularised system that can improve easily as we grow new systems / mechanics) and run this on the worlds and past worlds"; and the follow-ups on fuel, labour, capital, expansion and "the underlying physics ... the carrying capacity changes to reflect that")

## What it replaced
the economy check's fixed numbers (engine/capacity.py PLOT and WILD, landgen/economy.py) stay for 37.2 to replace (OPEN [[Q-28 The economy check counts crops that winter will clear|Q-28]])
