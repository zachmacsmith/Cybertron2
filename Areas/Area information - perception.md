# information/perception: Perception: what an agent sees and knows

What agents see, and how it changes, is the main design surface. An agent sees the node it is at and knows the rest only as it has seen, been told or read. Absence is never computed for it, prices are never computed for it, and other villages are known by the crafts of the lines born there.
