**Fallbacks as a person's standing setting: unset at the start, set or changed whenever they choose, instead of a fallback written every day**: Zach, 21 Nov: everyone seems always to fall back to firewood, which should not be the case; revisit; maybe a setting that optionally stays unset at the start and that they can set or adjust whenever they want; to be discussed and built with the standing rules for how a household's food is shared each night (W-37). Found (live runs of the runs world, 1,161 turns): the agents write a fallback in nearly every turn (1,147), choosing it each day, but the reply format's only example is (say, gather firewood) and a fallback repeats until the day's units are spent, so it fills much of the day: gather wild food 705, gather firewood 590, then repair 38, hunt 33.
