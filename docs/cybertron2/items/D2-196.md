**Hounds in wave 2, with the wolves; hawks in wave 3, with the falcon.** A hound is a trained beast held by a household and led along: it finds game over more ground, holds dangerous game at bay (less danger, D2-193), courses hares and deer, and guards houses and herds; it eats every day, is bred and trained, and can be killed or run off
