# Whether the smoke racks hold a real hut's load (Q-83)

Proposed: 250 fish a space, the fitting 2 spaces holding 500; 1 night a lot; 1 unit to hang 30 fish; 1 firewood per 60 fish; tending 1 unit a night (a named departure). Needs the fitting's own holds (keeping.py). The hearth rack's 3 nights need the same check.
